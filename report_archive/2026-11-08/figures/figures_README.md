# 竞赛报告图表说明

生成命令（在仓库根目录运行）：

```bash
wsl.exe -d Ubuntu24.04 -- python3 report_archive/2026-11-08/figures/make_figures.py
```

输出八组 `PNG / SVG / PDF`。绘图脚本直接读取归档 CSV；新增图不手填性能结果，关键行数、利用率和模型误差在绘图时断言核对。

## 配色与可读性

固定分类色为蓝 `#2A78D6`、橙 `#EB6834`、绿 `#1BAF7A`、黄 `#EDA100`。已运行 dataviz 校验器，lightness、chroma、CVD 与普通视觉区分均通过；绿色和黄色对白底对比度的 WARN 由直接标签、图例、坐标和报告数据表补足。不同 lane 在散点图中还使用不同点形，颜色不是唯一编码。

所有图均已实际渲染检查，未直接采用队友新版中含旧口径、文字重叠或统计范围不符的原图。

## 图 1：三层评测体系与实验流程

`fig_evaluation_pipeline` 区分两条输入轨道：同源 C/RVV 内核进入 QEMU/Spike、Ara2 RTL 和 K230；官方 Netlib HPL 2.3 是独立公开源码，只作为 K230 标准负载。图中明确“同一 Linux 二进制仅覆盖 QEMU 与 C908”，Ara2 与 C908 是同源代码分平台构建。

## 图 2：第二轮列分块优化实现与反汇编

`fig_panel_v2_evidence` 左侧为便于阅读的第二轮列分块优化核心伪代码，右侧为归档 `n128_nb32_opt_panel_v2/linpack.dump` 中真实存在的 `vlse64.v`、`vsse64.v` 和 `vfmacc.vf`。前两条对应跨步列缩放，`vfmacc.vf` 对应行更新；脚本在生成前检查这些指令确实存在于反汇编文件。

## 图 3：128阶和256阶Linpack求解全过程主结果

`fig_fullchain_n128_n256` 采用双面板优化路径图，直接读取 `local_linpack_summary.csv` 中4通道、分块32、mr8/m2、关闭分阶段计时的六条结果。128阶的基线版本、第一轮阶段向量化、第二轮列分块优化利用率为3.13%/8.23%/11.76%，加速1.00×/2.63×/3.75×；256阶为5.45%/14.14%/19.68%，加速1.00×/2.59×/3.61×。两种规模各自的残差和校验和一致。

## 图 4：128阶矩阵周期分解

`fig_n128_cycle_breakdown` 使用前后对比箭图，比较两次均开启分阶段计时的128阶、分块32运行。每个阶段由基线版本指向第二轮列分块优化，端点标注周期，右侧标注缩减比例。按列分块和右上矩阵块分别减少73.5%和88.1%，尾部矩阵乘基本持平；全过程总周期从571万降至153万（3.74×）。计时范围与图3的关闭分阶段计时结果分别呈现。

## 图 5：官方基准与双精度矩阵乘跨通道缩放

`fig_anchor_dgemm_scaling` 从 `cloud_all.csv` 重新计算官方 fmatmul 64³ 利用率，并选取256阶自研双精度矩阵乘已测代表点中的最优结果：2/4/8/16通道分别为63.86%/64.05%/54.93%/41.87%。其中8通道最优为 `mr8×lmul2` 的3,817,756周期、54.93%，不是固定 `mr4×lmul4` 的54.22%。2通道完成26变体完整扫描，其他通道为代表点复测。两种负载只比较缩放趋势，不互相替代性能结论。

## 图 6：理论推算与RTL周期对比

`fig_model_rtl_scatter` 读取 `e8_error.csv` 中49个手写RVV点，不使用旧图的57点混合口径。推算周期平均比实测少52.4%，37/49点出现推算利用率≥95%而实测<80%的假象。实线为 `y=x`，点线为 `y=x/2`，坐标为对数轴。40项动态指令计数与理论推算指令流逐项一致，但周期预测仍需RTL校准。

## 图 7：K230 B矩阵分块打包

`fig_k230_pack_b` 显示相同矩阵规模下双精度矩阵乘的中位吞吐。160/256/512/1024阶分别重复15/13/9/5次，B矩阵分块打包相对未打包收益为1.16×/1.71×/2.80×/5.63×。两组为不同二进制，图示仅为矩阵乘结果，不能外推为官方HPL分数。

## 图 8：K230 官方 HPL

`fig_hpl_openblas` 采用点线图。左图用前后对比箭头展示相同规模1000阶、分块128下 Reference BLAS 与 OpenBLAS RVV 的单次对比；右图按矩阵规模和分块配置展示 OpenBLAS 结果，其中4096阶、分块256为三次重复中位数，8192阶、分块256/512均为单次运行。所有条目均官方 PASSED、单 Linux CPU、单MPI进程。右图直接标注吞吐，分块256用连线呈现4096阶到8192阶的变化。
